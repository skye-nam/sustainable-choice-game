# Making the Sustainable Choice the Easy One

A short educational web game for CIV300 (Group G13). Travel to four countries, make everyday decisions, and see how rules, prices and infrastructure shape sustainable habits.

Play it in the browser: open the GitHub Pages link in this repository's "About" section.

The whole game is one file, `index.html`. All scenario text is in the `SCENARIOS` object at the top of its script.
